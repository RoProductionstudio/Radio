# Радио

Android-приложение для прослушивания российских радиостанций — без рекламы в приложении,
без регистрации и без трекеров.

## Возможности

- Готовый список станций: **Вести ФМ, Комсомольская правда, Маяк, Томские новости**, Радио России,
  Радио Культура, Радио Сибирь (Томск), Business FM, Европа Плюс, Русское Радио, Ретро FM и др.
- **Избранное** (♡) — со своим порядком (меню ⋮ → «Переместить выше/ниже»).
- **Плей / пауза / стоп**, работа в фоне и при выключенном экране, кнопки в уведомлении,
  на экране блокировки, в наушниках и в машине по Bluetooth.
- **Таймер сна** (5 мин … 3 ч, «+15 мин»): звук плавно стихает, и радио останавливается.
- **Поиск** любых станций в открытом каталоге radio-browser.info (кнопка «Томск» — местные станции).
- Если ссылка на поток перестала работать, приложение само ищет новый поток в каталоге и запоминает его.
- Свои станции и ручная правка ссылок (меню ⋮ → «Изменить ссылку» или долгое нажатие).

## Как установить

1. Откройте вкладку **Actions** репозитория → последний успешный запуск «Сборка APK».
2. Скачайте артефакт **Radio-apk** (zip), распакуйте `Radio.apk`.
3. Перенесите файл на телефон и откройте его. Разрешите установку из этого источника.

Требуется Android 8.0 и новее.

## Сборка вручную

```
./gradlew assembleRelease
```
APK: `app/build/outputs/apk/release/app-release.apk`.
